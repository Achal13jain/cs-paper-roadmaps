# Product roadmap

This roadmap prioritizes reader value and trustworthy curation over raw paper count.

## Now

- Publish standalone pages for every field.
- Make production URLs configurable for GitHub Pages and custom domains.
- Measure roadmap views, outbound paper opens, and reading progress.
- Document the editorial standard and remove unsupported freshness claims.

## Next

- Add explicit `last_reviewed` metadata to each roadmap after subject review.
- Generate a distinct social card for every roadmap.
- Link prerequisite concepts to earlier papers or learning resources.
- Offer Markdown and printable reading-group exports.
- Recruit volunteer reviewers for individual fields.

## Later

- Visualize paper dependencies as a compact graph.
- Add optional personal notes without requiring an account.
- Publish an RSS/Atom feed for curated additions.
- Provide four-week and eight-week reading-group schedules.

Feature requests should explain the reader problem they solve. New features should keep the static site fast, accessible, and usable without an account.
